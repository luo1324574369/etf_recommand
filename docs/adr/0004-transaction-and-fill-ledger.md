# ADR-0004：以成交回报和单事务账本为事实来源

## 状态

已接受

## 背景

当前交易日志在下单前按收盘价和滑点写入，交易指标直接从日志计算，可能与 Broker 实际成交不一致。Portfolio 买卖又分别提交交易、持仓和现金，异常时会产生部分提交。

## 决策

1. 策略只产生 `OrderIntent`。
2. 只有 Broker 确认的订单回报才生成 `Fill`。
3. 所有交易指标从 `Fill` 和闭合交易计算。
4. 交易、持仓、现金更新在一个数据库事务内完成，失败整体回滚。
5. 信号记录必须包含非空、经过校验的 `signal_date`。

## 影响

- 部分成交、撤单和拒单需要显式建模。
- 交易明细的产生时间从“发出订单”变为“确认成交”。
- 需要补充故障注入和账本一致性测试。
