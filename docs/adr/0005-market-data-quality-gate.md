# ADR-0005：市场数据质量门禁与可复现快照

## 状态

已接受

## 背景

系统面向每日收盘后的模拟交易辅助。仅依赖单一行情源或在异常时继续运行，会使信号、模拟成交和报告无法判断是否可信。当前数据源适配、复权处理和策略运行之间缺少明确的质量边界。

## 决策

1. Tushare Pro 作为主数据源，AkShare 用于交叉校验或备用采集。
2. 所有策略运行必须消费带版本、时间范围、来源和哈希的 `MarketDataSnapshot`。
3. 交易日、结构、OHLC、异常跳变、非负约束和可交易性检查失败时阻断。
4. 两源价格差超过 1%，或成交量差超过 10% 时阻断。
5. 信号使用复权价格，模拟成交使用原始价格；次日使用开盘价加固定滑点和手续费。
6. `DataQualityReport` 为 `blocked` 时不生成信号、不写入模拟订单，但生成阻断报告。
7. 复权因子必须携带 `adjustment_status=provided` 和来源；缺失、非法或未知来源不得静默降级为有效复权。
8. 回测区间额外校验结束日之后的第一条有效开盘价，作为次日开盘成交假设的必要输入。

## 影响

- 数据异常会减少可运行的交易日，这是保护模拟组合可信度的预期行为。
- 需要保存原始值、标准化值、跨源差异和校验结果。
- 数据源切换必须显式记录，禁止静默降级。
- 快照同时记录数据版本、请求区间、实际覆盖日期、记录数、缺失日期、重复记录和内容哈希。
