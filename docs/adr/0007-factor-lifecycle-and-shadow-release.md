# ADR-0007：因子生命周期、候选验证与影子发布

## 状态

已接受

## 背景

因子诊断可以发现 IC、分层收益或组合贡献恶化，但没有统一的失效状态、候选因子来源、验证门槛和发布回滚流程。自动替换会放大短期噪声和数据挖掘偏差，尤其不适合模拟交易辅助系统。

## 决策

1. 因子按月监控，正式新增、替换或调整只在季度发布窗口执行。
2. 失效判定综合最近24个月 RankIC、ICIR、分位收益、衰减、成本后表现、市场阶段稳定性和组合边际贡献。
3. 候选因子来源包括登记因子库、人工插件和 AI 生成代码，并记录来源和版本。
4. AI 生成代码只能在隔离沙箱中运行，不能访问正式数据、配置或注册表。
5. 候选必须通过最近24个月回测（前12个月选择期+后12个月最终盲测期），并完成相关性、边际贡献和风格暴露检查。
6. 人工批准后先影子运行 1–3 个月，随后才可进入正式模拟组合。
7. 每次正式变更保留旧策略版本、配置、报告和回滚入口。
8. OOS 证据必须包含完整区间和指标；影子完成必须绑定通过的数据质量门禁和正式回测报告，不能只提交手工收益数字。

## 影响

- 因子变更速度变慢，但可以降低过拟合和频繁切换风险。
- 需要因子注册表、候选状态机、沙箱执行环境和影子组合。
- 单因子高收益不足以触发发布，必须证明对组合有稳定的增量价值。
