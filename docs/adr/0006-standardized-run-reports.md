# ADR-0006：标准化运行报告与 AI-ready 事实数据

## 状态

已接受

## 背景

用户需要在不熟悉面板的情况下理解每日回测和模拟组合结果，并让 AI 基于可信事实生成解读。仅展示 Streamlit 图表无法保证历史可追溯，也容易让 AI 从图形猜测数字。

## 决策

1. 每次回测或模拟运行创建不可变的 `BacktestRun` 或 `SimulationRun`。
2. 按日期和 run ID 自动归档 `run-manifest.json`、`report.html`、`report.md` 和 `report-data.json`。
3. 报告固定比较当前策略、基准、上一次正式运行和影子策略。
4. JSON 只保存结构化事实、单位、口径和来源 ID，作为 AI 的输入事实层。
5. 数据质量阻断也必须生成报告，并明确标记 `blocked`，不输出交易建议。
6. AI 只生成带触发条件、依据、风险和失效条件的条件化建议，不直接修改策略或下单。

## 影响

- 报告目录需要版本管理和保留策略。
- Service 层需要稳定的报告 DTO；Streamlit 只负责展示、下载和历史对比。
- 旧报告若缺少数据快照或代码提交，必须标记为不可完全复现。
