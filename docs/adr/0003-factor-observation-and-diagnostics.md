# ADR-0003：统一因子观察与诊断模型

## 状态

已接受

## 背景

因子预热、实际打分、ICIR 权重和诊断面板分别执行不同的预处理与统计逻辑，且诊断中的分层收益和剔除月份尚未完整实现，导致面板结果不能代表策略实际行为。

## 决策

建立统一的 `FactorSnapshot`、`FactorObservation` 和 `FactorDiagnosticReport` 模型。所有因子路径共享：

- 截面范围和日期边界；
- 缺失值语义；
- Winsorize、group z-score 和方向调整；
- IC、ICIR、失效监控、分层收益和权重计算。

缺失估值数据使用 `None` 并从对应因子的截面计算中排除，不以 50.0 代替。

## 影响

- UI 只展示统一报告，不再自行推导指标。
- 数据不足时返回明确状态和缺失原因。
- 因子逻辑变更只需修改一个标准化路径。
