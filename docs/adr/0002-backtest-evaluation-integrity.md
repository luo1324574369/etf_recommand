# ADR-0002：回测数据边界与评估完整性

## 状态

已接受

## 背景

当前回测在 warm-up 阶段预加载完整价格历史，部分因子忽略 `end_date`；Walk-Forward 又使用全周期指标参与预设选择。这会造成未来数据泄漏和样本内选择偏差。

## 决策

1. 所有因子输入必须满足 `input_date <= current_date`。
2. 价格历史按当前 bar 增量维护，或按当前日期显式切片。
3. Walk-Forward 分为训练、验证和最终留出测试集。
4. 参数搜索只使用训练集，预设选择只使用验证集，最终测试集只运行一次。
5. 所有结果必须标记评估阶段、数据范围和是否参与选择。

## 影响

- 修复后历史收益可能下降，这是消除乐观偏差的预期结果。
- 旧回测报告必须标记为不可直接比较。
- 需要增加数据边界断言和防未来数据回归测试。
