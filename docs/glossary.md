# 领域术语表

| 术语 | 定义 |
|---|---|
| 核心仓位 | 固定占总资金 50% 的宽基 ETF 仓位，首次建仓后不参与调仓。 |
| 卫星仓位 | 剩余 50% 资金，由多因子策略选股和调仓。 |
| 因子截面 | 某一交易日对全部可用 ETF 计算得到的一组因子值。 |
| `FactorSnapshot` | 带有交易日期、因子原值、缺失状态和预处理值的因子截面快照。 |
| `FactorObservation` | 一个因子截面值与之后已结束持有期收益组成的统计观察。 |
| 前向收益 | 从因子观察日之后开始、在未来持有期结束时计算的收益；不得用于构造当日信号。 |
| RankIC | 同一截面中因子排序与后续收益排序的 Spearman 相关系数。 |
| ICIR | IC 均值与 IC 波动的比值，用于衡量因子信号稳定性。 |
| 分层收益 | 按因子暴露排序分为五组后，分别计算的后续收益序列。 |
| `OrderIntent` | 策略想要执行的订单意图，不代表已经成交。 |
| `Fill` | Broker 确认的实际成交记录，包含成交价、数量、费用和时间。 |
| 已闭合交易 | 从买入成交到对应卖出成交已完成配对的交易，用于计算胜率和盈亏。 |
| 评估阶段 | `train`、`validation` 或 `test`，表示某项指标是否参与参数选择。 |
| Walk-Forward | 按时间向前滚动训练和验证的参数评估方法。 |
| 最终留出测试集 | 参数和预设确定后才运行、绝不参与选择的 OOS 区间。 |
| 基准快照 | 某一日期对应的基准成分、权重和行业信息。 |
| 归因不可用 | 因基准历史数据、成分或权重缺失而不能可靠计算归因的明确状态。 |
| 账本一致性 | 交易记录、持仓数量和现金余额在同一事务后相互匹配的状态。 |
| `MarketDataSnapshot` | 一次可复现的行情输入快照，包含来源、抓取时间、覆盖区间、版本、哈希和质量状态。 |
| `DataQualityReport` | 对行情快照执行结构、价格、跨源和可交易性校验的报告；`blocked` 时不得生成信号或模拟订单。 |
| `BacktestRun` | 一次回测或模拟运行的不可变记录，关联参数、代码提交、数据快照、报告和结果哈希。 |
| AI-ready 事实数据 | 供 AI 阅读的结构化运行结果，只允许引用带单位、口径和来源 ID 的事实，不从图表猜数字。 |
| 条件化行动建议 | 由触发条件、依据、风险和失效条件组成的建议，不等同于无条件买入或卖出指令。 |
| `FactorDefinition` | 因子的版本化定义和数据依赖描述，必须记录来源、方向、缺失处理和审批状态。 |
| 因子候选 | 尚未进入正式策略、正在验证的因子版本，必须经过沙箱、OOS、组合贡献和压力测试；通过确定性门槛后可自动发布。 |
| 风险调整后收益目标 | 同时考虑年化收益、Sharpe、最大回撤、OOS 稳定性、换手率和基准超额收益的自动优化目标。 |
| `$etf-autopilot` | 由 Codex 执行的自主优化 Skill；负责报告读取、候选验证、自动发布、回滚和决策报告生成。 |
| 配置哈希 | 因子、参数、权重、约束和版本证据的确定性摘要，用于去重、审计和防止重复发布。 |
| 回滚锁 | 版本被自动回滚后，在没有新数据和新验证证据前禁止重新发布该版本的状态。 |
| 影子运行 | 新旧策略并行运行但不影响正式模拟组合的阶段，持续 1–3 个月并比较风险、收益、成本和风格暴露。 |
| 因子发布窗口 | 自主优化候选通过全部确定性门槛后即可发布的评估窗口；不设置固定季度限制。 |
